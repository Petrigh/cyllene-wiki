# Sesion 23

Cenan con las [madres de Harold](../characters/NPCs/madres_harold.md) en [Verna](../locations/settlements/verna.md). [Iri](../characters/party/iri.md) se gasta un monton de plata.

El [abuelo](../characters/NPCs/jebediah_creekwater.md) de Iri le contesta un *sending*, pero no le cree que sea Iri.

[Luthor](../characters/party/luthor.md) sueña que es un niño rubio de ojos celestes, hijo de [Iranon 1](../characters/NPCs/iranon.md). Se despierta con mucho dolor de cabeza.
