# DM notes

Anything in this folder is **excluded from the published site** by the `exclude:`
list in `_config.yml`. That keeps it off the web — but it does **not** keep it
off GitHub. A public repository shows every file in it, `exclude` or not.

Pick one:

- **Repo private, Pages private** (paid GitHub plan) — safest, everything here.
- **Repo public, secrets elsewhere** — keep this folder empty and put spoilers in
  a separate private repo, a local file, or your own Notion page.
- **Two repos** — public wiki, private DM notes. Most people end up here.

Suggested files if you do keep notes here: `plot.md`, `clocks.md`,
`npc-secrets.md`, `next-session.md`.
