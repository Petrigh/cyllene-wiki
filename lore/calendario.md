# Calendario

En Ta Phaestri conviven tres formas de contar los años.

## Las tres cuentas

| Sigla | Nombre | Arranca en |
| -- | -- | -- |
| Aureo | Calendario aureo | El primer heredero de [Aira](../locations/settlements/aira.md), cuando todavia se llamaba Aith Telperin |
| DF | Desde la Desfragmentacion | El año en que se abrio [La Grieta](../locations/regions/la_grieta.md) |
| DC | Despues de las Cruzadas | El año en que terminaron [Las Cruzadas](las_cruzadas.md) y se cerro la Grieta |

## La conversion

```
DC    = DF - 277
Aureo = DF + 10882
```

Hoy es el año **503 DC**, que es lo mismo que **780 DF** y que **11662 Aureo**.
