# Calendario

## Las estaciones
Hay  5 estaciones que dividen el año en, cada una dura 2 meses de 28 dias, Los meses estan nombrados en base a domains:

| Estacion | Meses |
| --- | --- |
| Magyc: primer periodo, grandes rituales, pasan cosas mágicas | Twilight; Arcana |
| Otoño | Trickery; Order | 
| Invierno | Tempest; Chaos; Death |
| Primavera | Life; Nature |
| Verano | War; Light |

### En Cyllene
En [Cyllene](../locations/continentes/cyllene.md) hay 5 meses en base a los 5 grandes.

| Meses Defragmentacion | Meses Despues de las Cruzadas |
| --- | --- |
| Arcana; Trickery | Naivara |
| Death; Life | Verna |
| Light; Twilight | Carnahan |
| Order; Chaos | Brolwund |
| Nature; War | Glavok |

## Los años

En Ta Phaestri conviven tres formas de contar los años.

### Las tres cuentas

| Sigla | Nombre | Arranca en |
| -- | -- | -- |
| Aureo | Calendario aureo | El primer heredero de [Aira](../locations/settlements/aira.md), cuando todavia se llamaba Aith Telperin |
| DF | Desde la Desfragmentacion | El año en que se abrio [La Grieta](../locations/regions/la_grieta.md) |
| DC | Despues de las Cruzadas | El año en que terminaron [Las Cruzadas](las_cruzadas.md) y se cerro la Grieta |

### La conversion

```
DC    = DF - 277
Aureo = DF + 10882
```

Hoy es el año **503 DC**, que es lo mismo que **780 DF** y que **11662 Aureo**.
